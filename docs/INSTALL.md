# インストール 0.2.0

最短操作はQUICKSTART.mdを参照してください。まず実データのないテスト保管庫を使います。

## iPhone

1. Obsidian 1.11.4以上を使用します。
2. このiPhone内に新しい空の保管庫を作ります。iCloudの実保管庫を初期試験に使いません。
3. プラグインZIPを展開し、main.jsとmanifest.jsonを保管庫の `.obsidian/plugins/obsidian-ai-drive-sync/` に配置。styles.cssは不要です。
4. iOS「ファイル」でドットフォルダが操作できない場合は、PCからのファイル共有やドットフォルダを保持するZIP展開などの方法を使用します。手動導入の操作自体はiPhone実機での未検証項目です。ストア公開やBRAT登録はしていません。
5. Obsidianを再起動し、コミュニティプラグインを利用可能にしてDrive Syncを有効化します。
6. Windowsのローカル認証ツールで認証し、10分以内に接続設定を取り込みます。Googleの認証画面はWindowsで操作します。iPhoneのブラウザからWindowsのlocalhostページは開けません。
7. 新規専用Driveフォルダを作り、バックアップ確認後に手動同期で試験。自動同期は試験後に有効化します。

SecretStorageはアプリ側の保存機能です。data.jsonを別端末へコピーして認証を引き継がず、各端末で接続設定を取り込みます。

## Windows認証ツール

Windows版Obsidianは不要です。Node.js 22以上を用意し、配布ZIPを展開、Start-Auth.cmdを開きます。通常利用はnpm ci不要です。利用中に一時待受するのは127.0.0.1だけです。ブラウザが開かなければコンソールのsetup URLを同じWindowsで開いてください。

取り込み後は認証ツールを終了してかまいません。再認証が必要になった場合だけもう一度起動します。Windowsの常時起動やCloudflare登録は不要です。

## Windowsでノートを読む

Google Drive for desktopで同じアカウントの同期先を開きます。必要に応じオフラインで使用可能にします。ドライブ文字は環境によって異なるため固定値を仮定しません。

Windows版Obsidianにも同じプラグインを導入できますが、同じフォルダにDrive for desktopとこのプラグインを同時に書き込ませないでください。初期運用はiPhoneだけがプラグイン同期担当、Windowsはファイルの参照用を推奨します。

## 更新・解除

自動同期をOFF、実行完了を待ち、バックアップしてからmain.jsとmanifest.jsonを更新。0.1.0からは先に旧接続の解除・Google側の取消を確認し、新しい方式で認証し直します。ノートと同期基準は削除しません。

接続解除はGoogleの許可の失効も試みるため、同じプロジェクトの他端末にも影響し得ます。アンインストールは解除後に無効化し、プラグインフォルダを削除します。Drive原本・履歴・競合コピーは自動削除しません。
