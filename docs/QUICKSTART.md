# 空のiPhone保管庫でノート1枚を同期する

0.2.0はサーバー契約・Cloudflare登録・独自ドメイン不要です。初回認証だけWindows上のローカルツールを使います。Windows版Obsidianは必要ありません。

0.2.1はクライアントIDとシークレットの直接入力にも対応します。初回はiPhoneへのプラグイン配置と有効化を先に済ませ、接続設定の入力画面を開いてからWindowsで認証してください。接続設定が10分で期限切れになってもGoogle Cloudのクライアントを作り直す必要はありません。Windowsツールで同じクライアントを使って再認証し、新しい接続設定を作ります。

## 1. Google Cloudで最初の設定

1. 自分のプロジェクトで **Google Drive API** を有効にします。
2. Google Auth Platformでアプリ名・自分のメール・Audienceを設定します。個人アカウントはExternalを選び、試験中はTestingのテストユーザーに自分を追加します。
3. 「クライアント」→「クライアントを作成」→種類 **デスクトップ アプリ**。WebアプリやiOSではありません。
4. 作成直後にクライアントIDとシークレットを安全に控えるか、JSONをダウンロードしWindowsに保管します。Googleの現行仕様ではシークレットの再表示・再ダウンロードはできないため、完了画面を閉じる前に保管します。すでに両方メモしていればJSONは不要です。認証情報をチャットへ貼り付けないでください。HTTPSのコールバックURL登録は不要です。

## 2. Windowsで接続設定を作る

1. 配布ZIPを展開。WindowsにNode.js 22以上を用意します（開発用npmライブラリのインストールは不要）。
2. `Start-Auth.cmd` を開くか、次を実行します。

```sh
node google-auth-helper.mjs
```

3. ブラウザに「AI Drive Sync 接続準備」が開きます。表示されなければ、コンソールに出た `http://127.0.0.1:…/setup/…` を同じWindowsのブラウザで開きます。
4. クライアントIDとシークレットをローカル画面の入力欄に入力します。メモがある場合はJSON不要です。ダウンロード済みJSONがある場合はそちらを選ぶこともできます。
5. 最初の1枚の試験は **最小権限** を選択。WindowsのAIが新しく作った任意のファイルも同期するなら **Drive全体** を選択します。後者はGoogle Drive全体の許可なので、範囲を理解して選んでください。
6. 「Googleの認証画面を開く」を押して自分でログイン・同意します。戻った画面の「接続設定と解除コードを表示する」を押します。
7. 暗号化した接続設定と32桁の解除コードが出ます。**10分以内に**次の取込を行います。設定をiPhoneへ渡し、コードは別に入力。両方を一緒に公開・共有しないでください。

ローカルツールは20分で終了し、認証情報をファイルやログに書きません。iPhoneからこのlocalhost URLを開くことはできません。渡すのは暗号化済みの設定文字列だけです。

## 3. iPhoneに入れる

1. 空のローカル保管庫を使います。Obsidian 1.11.4以上が必要です。
2. `main.js` と `manifest.json` を保管庫の `.obsidian/plugins/obsidian-ai-drive-sync/` に配置し、プラグインを有効化します。詳しくはINSTALL.md。配布ZIPの `obsidian-ai-drive-sync` フォルダを `plugins` 配下へ置く構造です。
3. プラグイン設定→「Windowsの接続設定を取り込む」。暗号化した設定と解除コードを入力し「Google接続を確認して取り込む」。
4. Googleへの直接接続確認が成功すると、認証情報はObsidian SecretStorageへ保存されます。Google認証と取込はここまでです。以後Windowsの常時起動は不要です。
5. 「Drive Sync Vaultを作成」を一度だけ押します。まず空の専用フォルダを使います。
6. 空の保管庫のコピーを保存し「バックアップを作成済み」をON。自動同期・起動時同期はまだOFFにします。

## 4. 1枚だけ往復させる

1. iPhoneで `同期テスト.md` を作り、`iPhoneからのテスト 001` と書きます。
2. 「今すぐ同期」。Driveの専用フォルダに通常の.mdができ、本文が同じか確認します。
3. WindowsのDrive for desktopで同期先を開き、同じ.mdの本文を `Windowsからのテスト 002` に書き換えます。最小権限でも、プラグインが作った同じファイルを編集する試験です。別ファイルへの置き換えやGoogle Docsへの変換はしません。
4. iPhoneで再度「今すぐ同期」。`002`が反映され、`AI Drive Sync/history`に旧版が残れば受信試験成功です。
5. iPhone側を再編集して送信試験。ETagが得られない・412以外で古いETagが通る等の問題があれば、本番利用せずTESTING.mdの条件付き更新試験で切り分けます。
6. 往復確認後に自動同期をON。既定は1分、起動時同期の待機は1秒、容量上限は1MB以上を除外です。

GoogleのTesting状態はDrive権限の更新トークンが原則7日で失効します。長期運用はOAUTH.mdの公開ステータスと再認証の説明を確認してください。無料・永久・メンテナンス不要を保証するものではありません。
