# Windows・外部アプリで使う

Driveには通常のMarkdownと添付ファイルを、フォルダ階層を維持して保存します。AI機能は含まれません。

Google Drive for desktopで同じ同期先フォルダを開くと、Windows版Obsidianやテキストエディターで編集できます。Windows側で保存した後は、ブラウザー版Driveにも本文が反映されたことを確認してからモバイル側で同期してください。

Windowsで新しく作ったファイルの取得には、Google認証ツールの「推奨」権限が必要です。自分の環境のDriveの場所を使い、ドライブ文字やパスを固定値だと考えないでください。同じ実フォルダにDrive for desktopと本プラグインを同時に書き込ませないでください。

Python等から通常のファイルとして読むこともできます。外部アプリへの接続や権限はそのアプリ側で管理してください。本プラグインは内容の要約、回答生成、外部AIへの送信を行いません。
