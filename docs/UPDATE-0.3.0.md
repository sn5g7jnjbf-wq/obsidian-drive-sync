# Drive Sync 0.3.0：Drive側での編集・移動と重複の選択

## 更新

保管庫をバックアップし、自動同期をOFFにして実行中の同期が終わるのを待ちます。プラグインを無効化し、`main.js`・`manifest.json`・`styles.css`を既存の `.obsidian/plugins/obsidian-ai-drive-sync/` に差し替えて再度有効化します。`data.json`と認証情報は残してください。新しい保管庫・Driveフォルダを作る必要や、再認証の必要はありません。ただしWindowsなどで作られたファイルには従来どおりDrive全体の権限が必要です。

GitHub Releaseの個別添付ファイルがプラグイン本体です。iOS標準「ファイル」アプリに隠しフォルダの表示メニューがあるとは案内しません。設定フォルダを操作できない環境では、利用中のプラグイン導入・更新手段を使って差し替えてください。

## Drive側で編集・整理した後

1. Drive上で通常のMarkdownファイルの本文を編集する、名前を変える、または同期先フォルダ内で移動します。
2. 端末で「今すぐ同期」を押します。同期済みファイルはDriveのファイルIDを基準に追跡します。
3. 移動先が空なら端末でも移動します。フォルダ移動は配下のファイルごとに反映します。空フォルダ単体は同期しません。
4. 同じファイルの本文も変わっていれば差分を確認して取り込みます。両側で本文が変わっていれば自動上書きせず競合として表示します。

Obsidian内のリンク文字列の自動書換えは行いません。必要なリンク修正は利用者が確認してください。同期先の外への移動・削除、端末側からの移動のDriveへの伝播は今回の対象外で、引き続き保留します。

## 端末の移動先に別ファイルがある場合

設定の「移動先のファイルが重複しています」→「使う内容を選ぶ」を押します。本文のプレビューを確認し、次のどれかを選択します。

- **両方残す**：Drive版を移動先へ取り込みます。端末の移動元・移動先は別名で残し、そのコピーも同期対象になります。
- **Drive側を使う**：Drive版を取り込みます。置き換える端末版は `AI Drive Sync/history/` へ移して残します。
- **端末側を使う**：移動先に現在ある端末版をDriveへ送信します。移動元の端末版と変更前のDrive版は履歴に残します。Driveへの送信には安全な更新用のETagが必要で、取得できない場合は停止します。
- **後で選ぶ**：変更せず保留します。

本文の競合一覧からも同じ選択ができます。プレビューはUTF-8の場合に先頭4000文字を表示します。バイナリは容量表示です。選択した後にファイルが編集されていれば、古い判断で上書きせず選び直しを求めます。

## Driveの同じフォルダに同名ファイルが複数ある場合

「Drive内の同名ファイル」から元の名前で残すファイルを選びます。選ばなかったファイルはDrive上で `Driveコピー` とID末尾を付けた別名に変更し、本文を消さずに残します。ローカルだけの別名ではなくDrive側の名前も変わります。Google形式・同名フォルダの重複はこの画面の対象外で、Drive側で名前を整理してください。

## 中断時

自動移動と選択処理は、変更前に処理計画を保存します。途中でアプリが閉じた場合は次回同期で同じ計画を再開します。再開前にファイルが別途編集・移動されていた場合は上書きせず停止します。この場合は履歴と別名コピーを確認し、必要な版を手動で復元してから同期基準を確認してください。保管庫やdata.jsonを消して解決しないでください。

複数の追跡済みファイルの名前を同時に入れ替える操作、大小文字・Unicodeだけが異なるパス衝突は安全のため保留・停止する場合があります。通常のフォルダ間移動とは区別してテストしてください。

この版の検証は型検査・ビルド・モックを使った自動テストです。新機能についてiPhone実機・実Google APIでの受け入れ試験は別途必要です。
