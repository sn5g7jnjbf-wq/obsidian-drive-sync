# テスト手順

## 自動試験

```sh
npm ci
npm run build
npm test
```

エンジンはメモリ保管庫／Driveを使い、実保管庫・実Googleアカウントに接続しません。通信層はrequestUrlを差し替えます。ローカル認証ツールは実際の127.0.0.1 HTTPサーバーを起動し、Google応答だけを差し替えてPKCE・state・再利用防止・Origin制限を検証します。暗号化設定は実Web Cryptoで検証します。実際のObsidian・iOS・Googleの動作を代替するものではありません。

## テスト保管庫を生成

```sh
node scripts/create-test-vault.mjs ../../work/test-vault
```

このスクリプトは空の新規ディレクトリのみ作成し、プラグイン本体と小さな試験用ファイル、1MBちょうどの添付を配置します。既存ディレクトリでは失敗するので、初期試験で実保管庫を使う必要がありません。生成先はObsidianで開けますが、自動でアプリを起動・プラグインを有効化しません。

## 実環境で必須の受け入れ試験（未実施）

各項目について端末・OS・Obsidian/API版・Googleアカウント種別・scope・結果・時刻を記録します。検証失敗時は元ファイルと両側バックアップを保持し、本番利用しません。

|段階|操作|合格条件|
|---|---|---|
|導入|iPhoneの新規ローカル保管庫へ2ファイルを配置|有効化・設定画面表示、Node APIエラーなし|
|認証|WindowsでDesktop client JSONを選びGoogleに同意、iPhoneへ取込|PKCE交換、SecretStorageのみ保存、再起動後の直接refresh成功|
|認証取消|同意を拒否／10分超過／callback2回|失敗時に新トークン保存なし、再接続可能、認可コード再利用不可|
|暗号化設定|違う解除コード／改ざん／10分超過／期限内再取込|違うcode・改ざん・期限切れは拒否。同じ設定の期限内再取込は可能であることを記録|
|独立運用|Windowsツールを終了してiPhoneで再同期|Googleへ直接refreshでき、Windowsが停止中でも同期可能|
|権限|drive.fileで新規専用フォルダを作成・一覧|正しいフォルダを選択可能、通常Driveに存在|
|初回|同名異内容のローカル／Driveファイル|両原本が変わらずDrive版競合コピーが作成|
|追加|小さな.mdとPNG、サブフォルダの追加|バイト単位で一致、普通のファイル、階層維持|
|更新|iPhoneのみ編集→同期|Drive更新、旧Drive内容がローカル履歴に残る|
|受信|Drive上の既存.mdだけを編集|iPhoneに反映、元ローカル内容が履歴に残る|
|競合|同じ.mdを両側で編集して同期|両原本を保持、Drive版コピー、同じ版の重複コピーなし|
|バイナリ|既存バイナリをDrive側で更新|元ローカルを保持し競合コピー作成|
|削除|追跡済みファイルを一方で削除・移動|相手側の削除・自動復元なし、保留表示|
|上限|1MBちょうど・直前・直後のファイル|以上を除外、しきい値を下げてもDrive削除なし|
|外部新規|Windowsで新規.mdを作成|drive.fileの可視性制限を記録。完全同期用途はdriveで確認|
|二重実行|手動同期を連打し定期同期も重ねる|一つの同期だけ実行|
|起動|接続済みで起動、未接続で起動、遅延中にOFF|設定遅延後のみ実行、未認証時は実行なし、OFFで取消|
|iOS停止|バックグラウンド・画面ロック・復帰|停止中の定期実行を前提にしない、復帰で再試行|
|障害|機内モード／回線切断／アップロード直後強制終了|原本保持、再起動後の再走査で収束、重複Drive IDなし|
|API制限|429・レート制限403・500・長いRetry-Afterを注入|指数待機、最大回数、後続再同期、bodyやtokenをログに出さない|
|条件付き更新|古いETagを使って同じファイルをmedia PATCH|**412で拒否、本文・revisionが変わらない**。無視されたら本番利用不可|
|同時更新|鮮度確認とPATCHの間で外部編集を注入|外部変更が条件付き更新で拒否・保持される。複数ライター非推奨|
|Windows|Drive for desktopで.mdを開く|UTF-8、日本語名、添付をローカルアプリで読める|
|AI|Python/Hermesでテスト本文を参照|実ファイル本文が読める、初期運用は読み取り専用|
|ChatGPT|テストノートの本文固有文字列を引用させる|名前だけでなく本文を取得。不可なら.txt添付等へ切替|

条件付き更新試験は使い捨てのファイルIDだけで行います。OAuthアクセストークンをコマンド履歴やテスト報告に貼り付けないでください。Drive API v3のメディア書き込み時にETag条件が保証されない環境では、現版の上書き同期を安全と認定できません。

## 障害解析

最終同期日時は「走査を完了した日時」であり、除外や競合がゼロという意味ではありません。設定画面の件数と一覧を合わせて確認します。data.jsonのjournalは未完了処理の手掛かりで、手動削除して強制成功にしません。ログを共有する場合もSecretStorage値・OAuth URL・トークンを含めないでください。
